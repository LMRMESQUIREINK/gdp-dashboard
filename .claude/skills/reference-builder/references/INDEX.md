# Reference library

Empty by design — no real reference screenshots exist in this sandbox to
add here honestly. Per the source guide's own Step 4, these have to be
real screenshots of real sites someone actually likes (motionsites.ai's
free gallery, awwwards.com, land-book.com), collected by a person
browsing and taking the screenshot themselves. Inventing placeholder
entries here would violate the method's own first rule — "study
references," not studied ones that don't exist — so this file stays a
template until real images are added to this folder.

Add one line per reference, in this format:

`- filename.png | category, mood | what's on the page | steal: the one thing worth stealing`

Example (format only, not a real entry):

`- saas-dark-video-hero.png | SaaS, dark | full-screen looping video behind a 2-line headline, tiny nav, one button | steal: the video plus huge type combo`
